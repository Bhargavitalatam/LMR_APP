# 🌍 Landmark Classification using CNN

## 📌 Description
This project predicts landmark IDs from images using a Convolutional Neural Network trained on Google Landmark Dataset (micro version).

---

## 🚀 Features
- Upload image
- CNN-based prediction
- Outputs Landmark ID

---

## 🧠 Tech Stack
- Python
- TensorFlow / Keras
- Streamlit
- NumPy
- Pillow

---

## ▶️ How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
